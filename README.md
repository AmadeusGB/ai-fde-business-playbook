# 《把AI带进经营》

**从业务流程到经营结果的企业AI落地指南**

作者：郭斌

本书面向企业经营者与技术团队，讨论怎样选择值得投入的 AI 项目、明确决策与交付责任、检验实际经营结果，并建立可持续的落地能力。全书五部、十八章，附十八份可用于工作的行动工具。
