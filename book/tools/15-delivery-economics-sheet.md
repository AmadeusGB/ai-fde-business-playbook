# 行动工具｜一类交付服务的经营检查表

作者设计。选一类范围清楚的服务填写，金额注明币种、期间和已发生／估计状态。不清楚的事项写明由谁核查、何时查清；不要用部署数代填收入。

买方可先填“服务与收入”中的收费与服务义务、“买方负担”和“本次决定”，再核对维护人员、支持范围及替换安排。拿不到的供方成本和续约数据保留未知，不凭报价倒推利润；供方经营者再补齐项目、公共投入和项目批次账。获客费用包含未成交的售前投入；空档、替换与跨国协作费用按实际活动归入，避免重复计算。

|---|---|

| 项目相关成本 | 交付、云／外购、支持与返工、获客：　　；空档及跨国协作费用： |
| 公共投入 | 建设总额：　　；维护总额：　　；分摊依据与未列费用： |
| 扩张条件 | 关键人员可用时间：　　；什么情况下增加人手：　　；后续支持费用估计： |
| 续约质量 | 原群体收入、退出、收缩、扩张：　　；原因与新增义务： |
| 买方负担 | 谁管理日常工作：　　；内部劳动与价值证据：　　；替换费用： |
| 本次决定 | 保持／扩大／缩小／暂缓／退出：　　；依据与失效条件：　　；负责人／复查日： |

使用后应能说清：下一笔收入增加哪些工作，由谁承担，以及哪项成本或能力变化会使本次决定失效。本表不是财务报表，也不以填写完成替代履约与结果证据。
