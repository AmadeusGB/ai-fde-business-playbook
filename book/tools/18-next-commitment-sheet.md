# 第18章行动工具｜下一阶段决定单

用途：为一项真实任务批准下一段工作。先填人名、日期及证据索引，再由有权者确认；空白表不是放行。日常动作沿原授权执行，变化或到期时复查。详细预算、测试和接手记录引用既有工具，不在本表重抄。

工具18-1｜下一阶段决定单

| 必填项 | 本次决定（填写空间） |
|---|---|
| 任务与当前状态 | 对象／版本／范围：____；已完成／未决：____ |
| 依据与边界 | 记录位置、分母及实际观察起止：____；尚不能声称：____ |
| 下一段工作 | 继续／缩小／补证／扩围验证／结束：____；交出什么：____ |
| 人员与时间 | 决定人：____；执行及接收人：____；替补：____；可用时段：____ |
| 资源上限 | 现金及已有义务索引：____；内部工时：____；任务量与复核安排：____ |
| 依赖未满足 | 缺口及负责人：____；限时补什么：____；到期不成走哪条路：____ |
| 提前复查与恢复 | 触发条件：____；谁可停止：____；谁凭什么批准恢复：____ |
| 到期与交接 | 截止日期及起算点：____；低频后续观察：____；已有任务和支持工作由谁接手：____ |

填写检验：请接收者据此说明明天接什么、不能做什么、条件变了找谁。任何一项说不清，先补决定。教学填法见表18-6，实际人名、上限和记录不可照抄。
