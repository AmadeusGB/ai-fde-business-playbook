# 行动工具14｜一次交付资产的复用验收

用于一项资产、一个目标用途。先填条件差异，再核复用证据；空白表示尚未核实，不表示通过。教学填写示例见图14-13。

工具14-1｜一次交付资产的复用验收

| 检查项 | 本次记录（填写或指向附件） |
|---|---|
| 资产及版本／维护人 | 名称：　　　　版本：　　　　维护人： |
| 原用途→新用途 | 原：　　　　　　　　新： |
| 可继承／须适配 | 可继承：　　　　　　差异及改动： |
| 必须重新验证／明确排除 | 新材料与接受条件：　　　不用于： |
| 换人复用记录 | 团队：　　　证据编号：　　　失败／未决： |
| 原作者支持 | 介入内容及工时：　　　是否代做关键决定： |
| 版本变化验证 | 变更：　　　受影响范围：　　　复验记录： |
| 工时与观察期 | 交付：　小时；后续：　小时；起止日期： |
| 尚未观察／继续责任 | 未经历的变化：　　　负责人／检查日期： |
| 本次决定 | 限范围接受／补充验证／不用：　　　接受人： |

使用说明：失败后补改资产，另选新材料复验；记录允许使用的支持，不能把原作者带做记为独立完成。公共建设另列；旧客户数据、授权和结论不自动转移。
