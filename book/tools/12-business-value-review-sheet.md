工具12-1｜经营结果核验单

| 核验内容 | 记录、结论或待补证据 |
|---|---|
| 对象与分母 | 纳入／排除规则；唯一任务编号；进入群体与本期接收群体分列 |
| 任务进入与处理情况 | 期初未结＋新进入＋其他调入＝接收＋其他关闭或调出＋期末未结 |
| 比较基线 | 前期／对照；起止时点；同期其他变化 |
| AI参与 | 哪个步骤；版本；首次使用及范围变动 |
| 工作结果 | 耗时／完成量；原始记录与提取日期 |
| 质量与反向指标 | 抽样方法；返工／投诉；严重问题 |
| 净工时及去向 | 扣新增负担；腾出的工时用于什么工作的记录；避免重复计算 |
| 现金与累计投入 | 实际减少／新增支出；一次性投入另列 |
| 结果与AI的关系能确认到什么程度 | 观察到变化／可能有贡献／在明确条件下估计增量效果 |
| 下一步 | 补测／限定继续／分批扩围／暂停；理由 |
