# 行动工具｜交付责任接口核对表

作者设计。选一项真实任务填写；每行写清谁负责、怎样确认完成、还有什么没解决。一人可以兼任多个岗位，但各项决定要分别记录。不清楚的事写明由谁查、何时查清。

工具16-1｜交付责任接口核对表

| 接口 | 本次记录 |
|---|---|
| 需求确认 | 任务／范围：　；业务确认者：　；依据版本： |
| 资料授权 | 提供者／批准者：　；用途、接收人员及所在地： |
| 构建集成 | 实现者：　；产品／原系统支持：　；交付物： |
| 验证检查 | 检查者：　；报告范围：　；未覆盖项： |
| 业务接收 | 接收者：　；可用范围：　；退回条件： |
| 采购付款 | 签约主体：　；验收确认：　；付款状态／日期及依据：　；待办： |
| 运行维护 | 受理入口：　；实际处理方：　；接手记录： |
| 经验反馈 | 业务依据保管者：　；问题送达谁：　；下次决定： |

抽查一行：材料由谁交出，谁确认可以接手；如果还不能，谁在什么时间内决定下一步。证据不足不填“已完成”；本表不替代合同或正式授权。
