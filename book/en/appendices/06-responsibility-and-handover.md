# Worksheet 06 Responsibility and takeover for one task

Designed by the author.

Choose a task preparing for trial operation and follow it from rule confirmation to exception recovery. In each row, name the authorized decision-maker, executor, and verification material. Add necessary review when one person holds several roles. The prompts below are not preassigned responsibilities.
